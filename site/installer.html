formalfred

A generative sequencer, with proofs.

Four lanes of Euclidean rhythm and note algorithms, 48 Braids oscillator shapes, chord progressions, and a butler. The lane logic is written and proved in Lean 4.

Install the latest release · Try it in your browser · Source and proofs

  • Four lanes that compose

    Euclidean rhythms with a note algorithm each: random, walk, up, down, bounce or a mutating loop.

  • Braids, all of it

    The 48 oscillator shapes of Mutable Instruments' Braids, 199 sounds and 128 patches, with a browser by engine or type.

  • Proved, not just tested

    The lane logic is Lean 4: in-scale notes, exact hit counts, and no stuck notes are theorems, checked by Lean's kernel.

Install FORMALFRED

The latest release downloads and is checked automatically. Connect your FM-1, then press Install.

2Connect

Plug the FM-1 in with a USB data cable and close other apps that use its MIDI port. Connect asks the browser for MIDI access with SysEx, then reads the device identity. No firmware data is sent in this step.

3Install

Install opens once the package is valid and the connected device matches it. The running firmware stages the update loader first, then the loader writes the whole image and the FM-1 restarts on its own. Success is reported only when the device comes back with the package identity.

Waiting for a package and a device.

During the write

  • Keep the FM-1 connected and powered, and keep this page open until it reports the installed identity.
  • The device restarts twice: into the update loader, then into the new firmware.
  • If the connection drops, press Connect and then Install again: a device left in update mode resumes the write.
  • If the FM-1 no longer starts, recovery needs FM-1-transporter; this page cannot recover every failure.
