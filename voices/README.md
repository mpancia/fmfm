# voices/

The synth voice: Mutable Instruments' Braids macro oscillator (all 48 shapes) behind a small C interface
(`voice.h`, `voice.cc`), plus the generated sound and patch tables (`presets.h`).

| Path | What it is | Origin |
|---|---|---|
| `braids/` | Braids' oscillators, unchanged | pichenettes/eurorack `f4cfa76`, MIT (`LICENSE-braids.txt`) |
| `braids/resources.cc` | Braids' tables; the pitch, resonator and filter tables are recomputed for 44.1 kHz | same, edited by `tools/braids_tables.py` |
| `stmlib/` | the few stmlib headers Braids includes | pichenettes/stmlib `d18def8`, MIT (`LICENSE-stmlib.txt`) |
| `shim/` | stand-ins for the standard headers Braids names (`<algorithm>`, `<cstring>`, `<new>`, ...) | ours |
| `voice.h`, `voice.cc` | the C interface, one voice per call | ours |
| `presets.h` | factory sounds and patches | generated by `tools/gen_presets.py` |

Braids was written for 96 kHz. Its pitch, resonator and filter tables depend on the sample rate and are
regenerated for 44.1 kHz. Bowing and blowing envelopes, and fixed constants inside some shapes, keep their 96 kHz
timing, so those sound slower than on the module.

`make audit` renders every factory sound and rejects any that is silent, clips, or changes level a lot between
octaves. `tools/gen_presets.py` drops sounds that fail it.
